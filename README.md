# Dr Zoe Hoare — personal website

The homepage is in `app/page.tsx`. Edit research, interests and grant funding in `app/site-content.ts`: add objects with a `title` and `description` to each section's `items` array. Empty sections show a “Details forthcoming” placeholder. Styles are in `app/globals.css`.

Run `npm install`, then `npm run dev` to preview. Run `npm run build` to validate a production build.
