# Dr Zoe Hoare — personal website

This is a plain static website. There is no framework, package manager, build step,
database or JavaScript.

## Edit a page

Open the matching file in `public/` and change the text directly:

| Page | File |
| --- | --- |
| Home | `public/index.html` |
| Research | `public/research/index.html` |
| Writing | `public/writing/index.html` |
| Interests | `public/interests/index.html` |

The appearance for every page is in `public/style.css`. The portrait is
`public/cartoon-headshot.jpg`.

To add a paragraph, copy an existing line beginning with `<p>` and edit the text.
To add a writing or interests entry, copy a whole `<article>...</article>` block.

## Preview

You can double-click `public/index.html` to open it in a browser. Links between
pages work when the `public/` folder is served or uploaded as a website.
